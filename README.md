> "Battery at 1%. My final words: I could have lasted all day, but someone kept refreshing the feed at 3 a.m."

The program writes that single line to `/output/entry.txt` for the make.fun bounty [Famous Last Words at 1 Percent](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4).
